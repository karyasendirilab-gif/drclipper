Kebijakan Privasi — DrClipper

DrClipper (“aplikasi”) menghormati privasi Anda. Dokumen ini menjelaskan data yang digunakan saat Anda memakai aplikasi untuk membuat klip pendek.

1. Data yang diakses

  • Video yang Anda pilih — diproses secara lokal di perangkat Anda untuk menghasilkan klip.
  • Informasi profil dasar platform (misalnya user.info.basic di TikTok) — digunakan hanya untuk mengidentifikasi akun Anda saat meminta izin publikasi.

Aplikasi tidak mengumpulkan nama, email, atau nomor telepon untuk disimpan di server kami. Kami tidak menjalankan server penyimpanan data pribadi.

2. Penggunaan data

Data profil dasar dipakai semata-mata untuk mengalirkan izin publikasi ke akun Anda. Video klip dikirim ke platform yang Anda pilih hanya setelah Anda mengonfirmasinya. Kami tidak menjual data Anda dan tidak menggunakannya untuk tujuan lain.

3. Izin dan pencabutan

Izin aplikasi diberikan melalui mekanisme resmi platform (OAuth). Anda dapat mencabut izin kapan saja melalui pengaturan akun platform tersebut. Setelah izin dicabut, aplikasi tidak dapat lagi mengunggah ke akun Anda.

4. Pihak ketiga

Aplikasi berinteraksi dengan platform tempat Anda mempublikasikan (misalnya TikTok). Penggunaan data oleh platform tersebut tunduk pada kebijakan privasi platform masing-masing.

5. Anak-anak

Aplikasi tidak ditujukan secara khusus untuk anak di bawah 13 tahun dan tidak sengaja mengumpulkan data dari mereka.
